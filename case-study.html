Executive Overview

OVERCLOCK is a high-speed, client-authoritative kinetic cyber air hockey platform built to eliminate the performance bottlenecks, latency stutter, and prohibitive server expenses of real-time web gaming. Standard web games rely on multi-megabyte monolithic engines (Unity WebGL, Phaser) and costly dedicated WebSocket game servers that suffer under mobile throttles and erratic networks.

OVERCLOCK proves that competitive 120 FPS action can run inside a mobile browser without external game engines. It unifies five purpose-built engines: (1) A 120Hz Deterministic Fixed-Step Physics Engine utilizing swept raycast sub-stepping to prevent tunneling at 2,500 px/s; (2) A Predictive Heuristic AI Engine calculating bank-shot trajectories and human reaction jitter across 4 difficulty tiers; (3) A Serverless WebRTC P2P Multiplayer Mesh achieving real-time 1v1 play with zero backend host costs; (4) A Zero-Allocation Canvas 2D Vector GPU Pipeline rendering pure 120Hz rasterization without Garbage Collection pauses; and (5) An Offline-First Progressive Web App (PWA) enabling installable standalone play on iOS and Android.

The Core Value Proposition: Delivering console-grade 120 FPS kinetic action, sub-15ms input-to-render responsiveness, and instantaneous peer-to-peer multiplayer directly in any mobile or desktop browser—with zero download footprint (<35KB gzipped) and zero ongoing cloud hosting costs.

Core Feature Modules: Detailed Architectural Breakdown

  • 1. Deterministic 120Hz Physics & Continuous Collision Detection (CCD): Built from mathematical first principles without heavy third-party physics packages. Uses an internal time accumulator (accumulator += dt) executing substeps at a constant fixedDt = 1/120s. Employs separating-axis normal relative velocity guards to eliminate double-hit impulses and prevents puck tunneling at supersonic velocities (>2,500 px/s) using clamped sub-step integration.
  • 2. Predictive Heuristic AI State Machine: Unlike simple tracker bots that linearly follow the puck's X-coordinate, OVERCLOCK's AI calculates multi-bounce raycast geometry off arena walls to predict the exact intercept point at the robot's defensive line. Features an intentional cognitive latency buffer (80ms–240ms based on difficulty) and aiming dispersion noise to simulate human biomechanical imperfections.
  • 3. Serverless WebRTC P2P Multiplayer Engine: Implements an ultra-low-latency real-time multiplayer protocol running directly between two browser peers. The match host runs the authoritative 120Hz physics simulation and broadcasts delta-compressed state payloads (puck coordinates, score, overdrive status) over reliable SCTP DataChannels. Eliminates monthly server hosting bills while reducing round-trip latency to pure peer-to-peer ping times.
  • 4. Zero-Allocation Canvas 2D Vector GPU Pipeline: Optimized to achieve native 60–120 FPS on resource-constrained mobile phones. Replaced expensive ctx.shadowBlur passes (which trigger multi-pass offscreen Gaussian convolutions on mobile GPUs) with pure vector styling, pre-calculated arena line geometries into a single batched draw call, and mutated coordinate buffers in-place to ensure zero Garbage Collection spikes during high-speed rallies.
  • 5. Offline-First Progressive Web App (PWA) Engine: Equipped with a custom Service Worker utilizing a Network-First strategy with offline fallback. Automatically registers web manifest specifications, supports standalone full-screen iOS and Android display modes, and manages persistent local saves (StorageManager) for unlocks, statistics, and boss progression without requiring third-party authentication.

Mathematical Physics & Collision Specifications

The core collision mechanics solve the classic air hockey momentum transfer problem: when a moving mallet strikes a moving puck, how is velocity transferred while guaranteeing that objects never overlap or tunnel?

// Separating-Axis Relative Velocity Guard: const relVelX = puck.vx - mallet.vx; const relVelY = puck.vy - mallet.vy; const relNormVel = relVelX * normalX + relVelY * normalY; // Crucial: If objects are already separating, ignore collision to prevent double-bounce glueing: if (relNormVel >= 0) return; // Positional De-penetration: const overlap = (puck.radius + mallet.radius) - distance; puck.x += normalX * overlap; puck.y += normalY * overlap; // Dynamic Kinetic Restitution: const impulse = -(1 + restitution) * relNormVel; puck.vx += normalX * impulse + mallet.vx * malletTransferFactor; puck.vy += normalY * impulse + mallet.vy * malletTransferFactor;
